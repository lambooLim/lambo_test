# Lambo Lab · 小实验室

**让想法，先发生。**

你好，我是 Lambo。这里用来记录想法、练习做东西，放一些简单但能用的小作品。

这个仓库的第一个作品是一页个人实验室主页，附带一个可以点击体验的「随机灵感卡」。

**[打开小实验室 →](https://lamboolim.github.io/lambo_test/)**

## 现在有什么

- **个人主页**：介绍这个小实验室和接下来的方向。
- **随机灵感卡**：8 个随手就能开始的小行动，点击按钮即可换一个，连续两次不会重复。
- **手机适配**：电脑和手机都可以浏览，支持键盘操作。

## 本地打开

下载本仓库后，直接用浏览器打开 `index.html` 即可。不需要安装依赖，也不需要账号或密钥。

```text
index.html   页面内容
style.css    页面样式与手机适配
app.js       随机灵感卡交互
README.md    项目说明
```
